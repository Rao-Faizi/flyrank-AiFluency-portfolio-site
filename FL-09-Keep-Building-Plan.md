**The Blueprint (The Three-Beat Shape):**
Whenever I complete a new significant project, I will return to this codebase and add a new object to the array following the exact same STAR format:
1.  **Problem:** What was the manual bottleneck or business issue?
2.  **Solution:** How did I automate or solve it? (e.g., What AI/N8N workflow did I build?)
3.  **Impact:** What was the measurable business outcome? (Time saved, cost reduced, accuracy improved).

**Steps:**
1. Open Antigravity (or Claude) using this exact project context so it retains my voice, tech stack, and identity kit.
2. Provide a raw brain-dump of the new project to the AI and ask it to format it into the 3-beat shape.
3. Paste the new project object into `components/CaseStudies.tsx`.
4. Run `npm run dev` to verify it looks good, then `git push origin master` to trigger the Vercel deploy.
